What it does

  1. 01

    Stream Detection

    Automatically detects supported direct videos and compatible HLS streams on Whop tabs you have access to without digging through dev tools.

  2. 02

    In-Player Download Button

    Places a clean Download video control right next to the Whop player so you can start saving supported videos in one click.

  3. 03

    Toolbar Tab Scanner

    Provides a Chrome toolbar popup (Whop Video Saver) with a Scan tab action to manually discover and select detected video streams.

  4. 04

    Native Chrome Downloads

    Hands off file downloads directly to Chrome's built-in Downloads manager so you can monitor progress and locate saved videos in chrome://downloads.
